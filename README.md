# Computer-Aided Language Learning and Evaluation for Arabic-Speaking Children

An AI-assisted language learning and assessment system designed to evaluate the English-speaking skills of Arabic-speaking children.

## Project Overview

The system analyzes children's spoken English responses and provides automated evaluation across multiple language-learning components, including grammar, pronunciation, and comprehension.

The project combines speech processing, natural language processing, machine learning, and web technologies within an integrated educational platform.

## Main Features

- Automated evaluation of spoken English responses
- Grammar, pronunciation, and comprehension assessment
- Speech recognition and text processing
- User accounts and conversation history
- Smart notes and language-learning feedback
- Support for students, university users, and administrators
